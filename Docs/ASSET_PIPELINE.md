# Project Mayhem — Free Realistic Asset Pipeline

## Approved art direction

- Realistic / photorealistic target.
- Free assets only during the initial production phase.
- Unreal Engine 5.8.
- The first district is a greybox for gameplay scale and systems. Primitive meshes are temporary placeholders, not final realistic art.

## Recommended source order

### 1. Epic City Sample

Epic announced an updated City Sample for Unreal Engine 5.8 on August 27, 2026. It is a free sample project available through Fab, the Unreal Editor Home Panel, or Epic Games Launcher. It demonstrates a large procedural city, curved roads and sidewalks, vegetation, PCG, and World Partition workflows.

Official announcement:
https://www.unrealengine.com/learning/city-sample-gets-a-major-update-with-pcg-and-unreal-mcp-workflows

Fab:
https://www.fab.com/

**Important:** City Sample is a large project. Do not merge its entire project into Project Mayhem. First claim/download it through the official Epic workflow, inspect engine compatibility and license terms, then migrate only selected assets using Unreal's Asset Migration workflow. Keep a backup before migration.

### 2. Quixel / Fab free assets

Use free, currently available scanned surfaces and props for asphalt, concrete, paving, brick, painted metal, road debris, curbs, rocks, vegetation, and urban props. Verify the current listing price and license on each asset's Fab page before adding it. Free status and availability can change.

### 3. Poly Haven

https://polyhaven.com/

Use CC0 HDRIs, PBR textures, and selected models. Prefer 2K/4K source textures initially; reserve 8K for hero assets after profiling. Check each asset's format and material setup before import.

### 4. Kenney / Quaternius

Use only where a suitable realistic asset is available. Many packs are stylized or low-poly, so do not mix them into the photorealistic hero environment without an art-direction review. Check the license on the creator's page.

## Import and migration rules

1. Download/claim assets through their official source.
2. Check license, engine version, dependencies, texture resolution, and Nanite suitability.
3. Open the source project in a compatible Unreal version if migrating from a sample project.
4. Use Unreal Asset Migration / Migrate to preserve references and dependencies.
5. Import only selected assets into the corresponding Project Mayhem folders.
6. Rebuild materials and collision where required; never assume a visual mesh has correct gameplay collision.
7. Record asset name, source URL, license, and migration date in Docs/ASSET_CREDITS.md.
8. Keep source assets unmodified where possible; create Project Mayhem material instances and variants separately.

## First district greybox

Content/Python/Build_PM_FirstDistrict.py generates a repeatable 300 m x 300 m urban blockout from Unreal's built-in primitive meshes. It includes:
- three streets in each direction, sidewalks, lane markings, and crosswalks
- varied building massing
- primitive placeholder street lamps and trees
- a PlayerStart and NavMeshBoundsVolume
- a cleanup tag so re-running removes only actors generated by this script

The blockout is not photorealistic and is not a final city asset pack. It exists to validate scale, road layout, player traversal, traffic, and pedestrian navigation before final art is integrated.

## Manual setup

The project descriptor enables Python Editor Script Plugin and Editor Scripting Utilities. Restart the editor after the plugin setup if Unreal requests it. Run the script using Tools > Execute Python Script and select Content/Python/Build_PM_FirstDistrict.py.

The Python API is editor-only and is not a gameplay scripting dependency.
